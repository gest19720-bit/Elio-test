For the technical side

Elio speaks MCP.

Connect Claude Desktop, or any MCP-compatible client, to your Elio workspace. Your tools get guarded, observable access — you keep the keys.

→
Scoped, read-only by default

Grant exactly the tools you want — view products, read metrics, generate reports. Writes are separate and optional.

→
Tokens are hashed, shown once

Elio stores only the SHA-256 hash. Copy the token when you create it; after that it can't be read back — only revoked.

→
Every request, logged

Tool, timestamp, latency, result. Revoke any connection with one click and existing clients stop working immediately.
